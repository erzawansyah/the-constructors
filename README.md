# The Constructors — an AI psychometric committee

AI agents that build psychological scales. Tell it what you want to measure about yourself, and a committee of AI agents follows the procedure a human psychometric team would: defining the construct, searching for published instruments, writing items, running an expert-panel review, and screening the items with simulated respondents before the scale reaches you.

> Simulation is not validation. Scales produced here are screening drafts, not validated or diagnostic instruments.
